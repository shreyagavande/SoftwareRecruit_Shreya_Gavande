A little guidance

Your photos, beautifully organized.

From a random discovery to a collection that feels like you.

A small collection, made for this demo.

This sample application contains only 10 photographs. Generate random photo selects one from that collection; it does not create new images or pull from an unlimited feed. Once all 10 have been sent, there are no more sample photos to receive in that run.

  1. Generate a random photo

    When the status says Connected, click + Generate random photo. A photograph arrives from the sample collection and is automatically saved with the unlabeled tag.

  2. Open it up

    Click any photo in the gallery. A large preview opens on the left, with all your editing controls in the sidebar on the right. On a smaller screen, the controls appear below the photo.

  3. Give it a name and tags

    Change the photo name and enter tags separated by commas, such as Toronto, sunset, architecture. Choose a colour for each tag, then click Save changes. Here, editing means organizing the name and details; it does not change the image pixels.

  4. Make a collection

    In the sidebar’s Folder field, type a new folder name or choose an existing one, then save. Use the Folder filter above the gallery to browse that collection.

  5. Find it again

    Search by photo name or tag using the search bar. Use Unlabeled to find photos that still need tags; the count shows how many remain in the current view. Click a result to reopen it and make more changes.

  6. Keep, archive, or delete

    Archive photo moves it out of your Library. Find it in Archive and choose Restore to library to bring it back. Delete photo removes the saved entry after confirmation. Your original image file is not deleted.

Make yourself at home

Switch between light and dark mode using the top-right button or Settings. Your photos and saved edits stay in this browser on this device. Return using the same browser and website address.
